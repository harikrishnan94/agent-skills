# Contributing

## Commits

- Subject: imperative mood, 50 characters max, no trailing period.
- Body: prose explaining why the change is needed. No bullet lists.
- Disclosure (mandatory): any commit containing AI-generated content MUST
  carry the trailer `Assisted-by: <tool name>`.

## Pull requests

- Descriptions are prose paragraphs, 20 lines max.
- Must include a line starting with `Testing:` describing how the change
  was verified.
- No bullet lists, no checklists, no emoji.
